# 美食
# 前言

看到杭州的美食，大家可能都会惊叹："杭州哪里会有美食呢？"。其实非也，当然我并不是说杭州真的有绝顶好吃而且还隐藏很深的特色菜，而是某些餐厅的菜还不错，当然不错的标准可能很低也就是略高于食堂吧。

# 紫金港周边
## 堕落街

堕落街其实就是紫金港北门的一条全是小吃的街，记得第一次去的时候和室友感慨堕落街似乎也不是很堕落呀！其实我在临近大学开学报到时就听闻过堕落街，有一部言情小说《难哄》中男女主所依托的故事背景似乎就有堕落街，而为什么我会看到《难哄》的这段，那是高中时的故事就不赘述了。不论如何，我对堕落街的初始预期是很高的，但是它的表现只能说一般般吧。

要说堕落街上有什么好吃的，应该有一家叫 ==老奶奶卷饼== ，平日里那里排队人最多，我是没有吃过，但据说挺好吃的。在它旁边有一家买炸物的店铺，平日里排队人数没有很多，但是我认为滋味也很不错，其中最好吃的我认为莫过于是 ==炸鸡腿== 了，鸡腿的热气与香辛料的味道混合着往外窜，咬上那么一口外酥里嫩、鲜嫩多汁，非常满足。价格似乎是 15 元 2 只还是 3 只来着，我有些记不清楚了。我不知道是否是浙江人爱吃 ==梅干菜烧饼==，每次逛堕落街无甚好吃，台州的室友就会去买一份梅干菜烧饼，我不太吃得来。 

堕落街上还有一家买 ==黄焖鸡米饭== 的店，老板看起来非常干练，店里也经常挤满顾客，大多都是学生，价格也算公道，滋味嘛，我认为略胜于正常的黄焖鸡米饭吧，主要得胜的点可能在于它的味道没有那么同质化。再往堕落街前面走到路口，有一家买 ==小煎包== 的店，这家店的小煎包挺好吃的，特别是对比食堂的煎物，肉包滋味明显更加新鲜，不会有发酸的感觉。路口向左拐是一家 ==西北菜馆==，西北以面为主食，陕西室友觉得这家面店滋味还挺不错的，我也这么认为，特别是 ==羊肉孜然拌面==，味道太香了，羊肉带着羊油的脂香味再配上孜然的辛香味与吃劲的宽面，一口下去涌上来的滋味真是能把人香迷糊。正所谓“吃面不吃蒜，滋味少一半”，配着生蒜吃，正好解腻！原先我不爱吃生蒜且不理解吃生蒜的人，吃到西北的拌面，我才明白生蒜的滋味真是不错啊！
