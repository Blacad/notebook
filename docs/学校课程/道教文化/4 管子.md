
## 一、管子其人其书

- 管仲（？—前645），名夷吾，字仲，齐国政治家，辅佐齐桓公称霸，法家先驱
- 《管子》：非一人一时之作，战国中后期稷下学者编纂的著作总集
	- 刘向校订，原86篇，今存76篇
	- 内容杂糅道、法、儒、阴阳等，是"百家争鸣"的产物
	- 与道教关系最密切者，是其中的**黄老道家**诸篇

## 二、稷下学宫与黄老之学

- 稷下学宫：田齐所设，战国学术中心，百家争鸣之地
- 黄老之学：以道论法、道法结合，兼采阴阳、儒、墨
- 稷下黄老（郭沫若称"稷下黄老学派"）
	- 代表文献：《管子》四篇
	- 相关人物：宋钘、尹文、慎到、田骈、环渊等（四篇作者归属有争议）
- 学术谱系
	- 稷下黄老 → 韩非《解老》《喻老》 → 汉初黄老之治（文景之治） → 《淮南子》 → 道教

## 三、《管子》四篇——黄老道家的核心

- 指《心术上》《心术下》《白心》《内业》四篇（约六千余言）
- 篇名即点出"心""气"主题，历来被视为道教哲学的源头之一

### 1. 精气说（道即精气）

- "凡物之精，此则为生。下生五谷，上为列星……藏于胸中，谓之圣人"（《内业》）
- "精也者，气之精者也"
- 把老子的"道"落实为"精气"，使道具有物质性
- 精气：万物与生命的本源，也是智慧（圣人）的根源
- 人有精与形："天出其精，地出其形，合此以为人"
- 心为"精舍"：心是精气留存之所

### 2. 静因之道（心术）

- 心术：治心之术
	- "心之在体，君之位也；九窍之有职，官之分也"——心为君，统摄九窍
- 静："毋先物动，以观其则"，"动则失位，静乃自得"
- 因："因也者，舍己而以物为法者也"——顺应、因循，不师心自用
- 去智与故：摆脱欲望好恶，"虚其欲，神将入舍；扫除不洁，神乃留处"
- 工夫：虚、静、一，内静外敬，使精气留存、道乃自定

### 3. 道、德与生成

- "德者道之舍，物得以生"（《心术上》）——德是道在万物中的落实
- 道 → 德 → 万物，上承老子"道生之，德畜之"
- 道—气—万物：气是道生成万物的中介

### 4. 内业与养生

- "内业"即内在的修养工夫，修心养气
- 保精、蓄气、去欲，以求内心虚静
- 由治身养生上通治国，为后世养生方术之源

### 5. 治身与治国同构

- 心术既通治身（养生），又通治国（政治）
- "身国同构"：治身如治国，治国如治心——道教"身国同治"之滥觞
- 四篇虽属道家，已含法家倾向（法以道为依据），兼具融通诸家的色彩

## 四、管子与道教的关联

- **义理**：道论、精气说 → 道教宇宙论、气化论、精气神学说
- **修炼**：静因、内业、去欲养气 → 道教养生、存思、内丹
	- "致虚静"入于"性"功，修养精气神入于"命"功
- **政治**：道法结合 → 道教"身国同治"
- **医学**：精气养生论 → 中医基本纲领与方技文化源头之一
- **文献**：明《正统道藏》未收《管子》（相传宋代《道藏》曾收），但其思想影响不可抹煞

## 五、小结

- 《管子》是"道"与"法"之间的桥梁
- 老子之道 → 稷下精气说（黄老） → 汉初黄老 → 道教哲学与修炼
