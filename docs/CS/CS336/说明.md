## Stanford CS336 · Language Modeling from Scratch

- [课程官网](https://cs336.stanford.edu/)
- 本地材料版本：**Spring 2026**，依据 `Slides/README.md` 及讲义中的课程标识整理。

CS336 围绕“从零搭建语言模型”展开：不仅理解 Transformer 的公式，还要亲手实现分词器、模型与训练循环，核算显存和计算量，编写高效 GPU kernel，组织分布式训练，并处理数据、评估与后训练。贯穿全课的问题是：**在有限的数据、算力、显存与通信预算下，怎样构建最有效的模型？** 小模型实验用于学习机制与工程方法，但具体经验能否迁移到更大规模，需要通过 scaling 实验验证。

- 与 [李宏毅 2026 笔记](../%E5%AE%8F%E6%AF%852526/%E5%AE%8F%E6%AF%8526/%E8%AF%B4%E6%98%8E.md) 的侧重点不同：后者更关注 Agent、推理与自我成长，CS336 更深入模型训练、底层系统与数据工程；位置编码、KV Cache、FlashAttention 等主题可以对照阅读。
- 学习基础：线性代数、概率、反向传播，以及 Python / PyTorch 张量操作；系统部分还会涉及 GPU 存储层次、性能测量与分布式通信。
- 讲义列出 5 组作业：**Basics、Systems、Scaling Laws、Data、Alignment**，通过实现、测试与受限预算实验理解原理。这里记录课程内容，不代替实际完成作业。

## 串起全课的几条线

- **数据搬运**：L2 的 Roofline → L5–6 的片上复用 → L7–8 的跨卡通信 → L10 的 KV 与服务调度 → L16 的 rollout 效率。
- **固定预算决策**：L1 的效率视角 → L9–11 的 scaling / recipe → L14 的数据质量、数量与重复率 → L10 的训练—部署成本。
- **目标与验证**：L12 定义评估 → L13–14 选择数据 → L15 对齐偏好 → L16 利用可验证奖励 → L17 处理多模态目标与表示差异。
