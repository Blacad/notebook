## Stanford CS106L · Standard C++ Programming

- [课程官网](https://web.stanford.edu/class/cs106l/)
- 本地资料：原目录标记为 **Winter 2021**，但实际 PDF 混有 **Fall 2020、Winter 2020、Winter 2021** 的页首标注。本笔记以本地文件及编号为准，不与官网当前学期的讲次安排混用。

CS106L 是 Stanford 的标准 C++ 编程课程，重点是理解现代 C++ 的语言特性与设计思路：不仅会使用容器，还要知道泛型接口怎样组织，const 如何表达只读约束，复制与移动怎样影响资源，以及 RAII 如何让清理过程变得可靠。[课程介绍](https://web.stanford.edu/class/cs106l/)

这套讲义从类型、结构体、初始化和引用起步，进入 Streams 与 STL，再围绕模板类、运算符、特殊成员函数、移动语义和智能指针完成类设计。贯穿其中的问题是：**能否用清晰的类型表达意图，在保持效率的同时减少手工管理资源的风险？** 课程目标不是背完语法，而是能阅读文档、识别接口约束，并写出可组合、可维护的代码。

- 学习基础：已有函数、循环、基本数据结构与对象/类的概念；从 Python 转入可先读 Lecture0。课程频繁对比 Stanford 教学库与标准库，两者不是同一套接口。
- 练习背景：本地课件介绍了 WikiRacer、Stylometry 与自定义 HashMap 等实践。笔记整理知识与设计思路，不将历史 deadline、选课信息或展示代码当成当前要求/完整作业答案。

## 串起全课的三条线

- **通用性**：L2 组合类型 → L5–6 容器与 iterator → L7–8 模板、predicate 与 lambda → L9 综合算法 → L10 模板类。
- **值语义与成本**：L3 复制/引用 → L11 const → L12 自然接口 → L13 正确复制 → L14 资源移动。
- **所有权与安全**：L3 生命周期 → L13 资源复制与析构 → L14 转移所有权 → L15 RAII 与智能指针；能用标准资源类型组合解决时，优先 Rule of Zero。
