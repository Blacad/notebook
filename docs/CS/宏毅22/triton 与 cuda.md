
| 对比维度        | CUDA C++                        | Triton                                                     |
| ----------- | ------------------------------- | ---------------------------------------------------------- |
| **语言类型**    | 显式静态编译语言（类似 C++）                | 嵌在 Python 中的静态编译型 DSL（类似 Numba，但更激进）                       |
| **“编译器”**   | `nvcc` → PTX/cubin              | Triton Compiler → PTX/cubin                                |
| **类比编译器角色** | 像 `g++`，执行你给定的指令，做局部优化          | 像一个**资深 CUDA 架构师坐镇编译器**，看你写的简单块描述，然后**自动优化为相应cuda写的cubin** |
| **执行方式**    | 直接编译，或在运行时通过 JIT 从 PTX 生成 cubin | JIT（即时编译）：第一次运行时编译成 cubin，之后缓存，无解释开销                       |
| **优化由谁负责**  | **人**：手动分块、共享内存、合并访存            | **编译器**：自动完成绝大多数优化                                         |

- CUDA 更像手动挡极致的压榨性能但是很麻烦，triton 则是自动挡编译器会帮你优化大多数细节但是极致优化略差于CUDA
