- 说明
	- 本次作业是实现强化学习的 policy gradient 以及 Actor-Critic 进而通过 RL 使得模型完成相应的任务 即 LunarLander 月球着落器


- 常规的pipeline如下
	- 数据集准备 -> 模型搭建 -> 训练器搭建 -> 推理过程
		- 训练器搭建中涉及 数据读取、优化器/损失函数设计以及学习率规划器等等环节

- 针对 RL类的pipeline有所不同
	- 环境准备 -> 模型搭建 -> 训练过程 -> 推理验证

	- 环境准备
		- 我们给环境 action，环境返回 observation, reward, terminated, truncated, info 信息
			- observation 是 观察到的信息，近似等同于 state --- 描述该状态下各数据的向量
			- reward 是该 action 的奖励
			- terminated、truncated 描述 任务结束的状态，前者为 True 表示正常按照MDP结束，后者 True 表示达到某种条件结束
			- info 描述额外信息比如辅助记录、评估、调试
		- 这里的环境直接使用 OpenAI 提供的 gym 库
		- `env = gym.make("LunarLander-v2", render_mode="rgb_array")`

	- 模型搭建
		- 采用 Actor-Critic 架构，二者共享前部分网络，后部分网络分开，一者用作 Actor，另一者用作 Critic
		- 同时初始化时定义优化器 和 存储 critic 结果的list
		- 模型中除了 forward 方法，同时实现 learn 和 sample 方法
			- sample中完成动作产出和动作概率
				- 把概率构造成离散的 categorical distribution方便后续采样动作
					- `action_dist = Categorical(action_prob)` 
					- `action = action_dist.sample()`
				- 动作概率
					- `log_prob = action_dist.log_prob(action)`
			- learn 中完成梯度更新
				- `loss = (-log_probs * (rewards - values.detach())).sum() + F.smooth_l1_loss(values, rewards)`
				- 其中
					- 第一项只有 `log_probs` 对参数求导(values detach掉当成常数) <- policy gradient
					- 第二项 `values` 正常回传梯度，类似于 MSE取拟合奖励信号 <- value gradient
		- 输入给模型的是 observation(state)，模型输出 action 和 对应的 logprob

- 训练过程
	- 训练过程也是分 batch，每个 batch 里有 5 个 episode，每个batch 更新一次
	- 其实一个 episode 就可以更新一次，因为 rewards 即 折扣未来收益在一个 episode中就已经可以得出了
