- 说明
	- 本次任务是做 领域适配任务，即我们的训练任务和真实的测试任务有所不同，比如 我们真实的测试任务是在 真实世界的场景，但是训练任务中的数据是来自 GTA-5
	- 我们采用一种常见的 DaNNs(Domain Adaption Neural Networks) 解法，其训练过程称为 DAT(Domain Adversarial Training)
		- 前半部分网络负责 特征提取，尽可能让 Test Domain 和 Training Domain 提取的特征相近
		- 后半部分网络负责 分类/处理提取的特征
		- 前半部分需要使用类似 GAN 的训练方式
			- 引入 discriminator 让其判断经过 特征提取网络 的特征属于哪个 domain


- 数据集准备 -> 模型搭建 -> 训练器搭建 -> 推理过程
	- 训练器搭建中涉及 数据读取、优化器/损失函数设计以及学习率规划器等等环节


- 数据集准备
	- 用了一个领域知识，因为我们训练采用的是真实图片但是 target 的是涂鸦，本处将真实图片(先进行灰度处理)经过 `cv2.Canny (image, low_threshold, high_threshold)`  转化成线条形
	- 后续就是常规的针对image的数据增强转换

- 模型搭建
	- 三个模型
		- 特征提取器 --- 简单的CNN
		- domain 分类器 --- MLP
		- label 分类器 --- MLP

- 训练器搭建
	- 基于 GAN 的逻辑，先训练 domain 分类器再训练特征提取器和label分类器
	- label 损失采用 CE，domain 损失采用 BCE
	- 均采用 Adam 算法
	- 在 stage 1 训练阶段 loss 就是简单的 BCE
	- 在 stage 2 训练阶段 loss 将 label 的 CE 和 domain 的 BCE 的负数 合并
	- 有一个 lambda 量用于调控 stage 2 的 domain loss 的占比，它在epoch 循环层中调控，当 epoch 越到后面时 lambda 的值越大
	- `zip` 函数的精准解释
		- `zip` 类似于并行遍历多个可迭代对象，每轮从各对象中各取一个元素并组合成元组返回，直到最短的可迭代对象被遍历完


- 推理过程
	- 就是简单将特征提取器和label 分类器变成 eval，然后把数据丢进去
	- 把 `result` 中的多个 NumPy 数组沿某一个已有维度拼接起来
		- `result = np.concatenate(result)`
		- `result = [ np.array([1, 2, 3]), np.array([4, 5]), np.array([6, 7, 8]) ]` -> `[1 2 3 4 5 6 7 8]`


- 分析过程
	- 采用 t-SNE 分析提取后的特征
		- `from sklearn import manifold`
		- `manifold.TSNE(n_components=2, init='random', random_state=5, verbose=1).fit_transform(data)`
