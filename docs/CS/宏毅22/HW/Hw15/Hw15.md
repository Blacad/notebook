- 说明
	- 本次作业是 使用 MAML 进行元学习，所谓 MAML 并不是去学习出一套好的神经网络参数，而是学习一套超参数使得模型依据该超参数在多个任务下训练后的综合性能最好
	- 本次具体面临的任务是 Omniglot 就是一堆 手写涂画
		- 训练数据，共有30个词表，每个词表会有很多个手写涂画的单词 character，每个 character 有 20 个涂画的具体例子(每个具体例子不完全一致)
		- 测试数据，共有 640 个支持与询问对，每个对里有5个支持的例子和5个询问的例子
		- 针对该任务 一个character 就是一个类，而具体例子就是一个shot
		- 本次任务针对 5-way 1 shot，也就是每个训练数据和测试数据都是 5个类每个类只有一个例子

- 常规的pipeline如下
	- 数据集准备 -> 模型搭建 -> 训练器搭建 -> 推理过程
		- 训练器搭建中涉及 数据读取、优化器/损失函数设计以及学习率规划器等等环节


- 数据集准备
	- 数据集每次返回某个词表的指定的 idx 的character，然后从该character中取出 k_shot+q_query 个图片，这是一个样本(1个类)


- 模型搭建
	- 常规的CNN模型，但是相比常规模型定义新增方法 `functional_forward(self,x,params)`
		- 该方法中 `x` 是模型的输入，`params` 是模型的参数，它的作用是能够在模型结构不变的情况下通过传入不同的模型参数得到对应的forward结果

- 训练器搭建
	- dataloader 在这里每次会返回 (n_ways, k_shot+q_query, C,H,W) 相当于返回 n_ways个类(character)，每个类有 k_shot+q_query 个例子
		- 后续再经过 `get_meta_batch` 处理成为了 (n_ways*(k_shot+q_query),C,H,W) 的样子
		- 可见每个meta_batch 就是一个完整的分类任务，所以完整的meta训练有非常多的完整分类任务
