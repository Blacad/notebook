- 模型搭建
	- 模型搭建这里采用 depth_wise + point_wise 来减小网络
		- `torch` 的卷积初始化 `torch.nn.Conv2d(in_channels, out_channels, kernel_size, stride, padding，groups)`
			- 在 `Conv2d` 中，假设输入有 `4` 个通道，卷积核空间大小为 `(3,3)`。当 `groups=2` 时，输入通道被分为2组，每个group为 $(4/2=2,H,W)$ ，单个 filter 的尺寸为：$(4/2=2,3,3)$ 即一个 filter 包含 `2` 个 `(3,3)` 权重切片，分别与group的对应输入通道卷积，再将各通道结果相加，最终得到一个输出 channel
			- `out_channels` 决定 filter 的数量，也就是输出 channel 数，而单个filter尺寸为$\left(\frac{in_{channels}}{groups}, K_h,K_w  \right)$ 
				- 其中`groups` 决定 channel 的分组方式；每个 filter 只处理一个 group 内的输入 channels 且 filter 的 channel 尺寸与该group的channel尺寸一致
				- 相当于一个输入被拆分成 groups 个组，每个组由一个filter处理
			- 因此，in_channels、groups、kernel_size 决定单个filter的完整尺寸，out_channels 决定 filter的数量，stride 和 padding 决定卷积方式
		- 基于上述卷积可以实现  depth_wise + point_wise
			- `depth_wise` --- `nn.Conv2d(ic, ic, kernel_size, stride=stride, padding=padding, groups=ic)`
			- `point_wise` --- `nn.Conv2d(ic, oc, 1)`
	- hook 方法
		- pytorch 规定 注册到 module 上的 hook 函数签名为 `hook(module,input,output)`，注册方式 `module.register_forward_hook(hook_fun)`
		- 这样模型在forward时每次经过该module后都会执行该hook函数
		- 其实有三种hook形式
			- 前向前
				- `module.register_forward_pre_hook(hook)`
				- `hook(module, input)`
			- 前向后
				- `module.register_forward_hook(hook)`
				- `hook(module,input,output)`
			- 反向
				- `module.register_full_backward_hook(hook)`
				- `hook(module, grad_input, grad_output)`


- 训练器搭建
	- 损失设计
		- 本处采用 KD 知识蒸馏
		- `loss = (10*percent*percent) * loss_logits + loss_fea`
			- 第一项 `loss_logits`
				- `loss_fn(logits, labels, teacher_logits, alpha=1 - percent*percent)`
					- `student_T = (student_logits/temperature).softmax(dim=-1)`
					- `teacher_T = (teacher_logits/temperature).softmax(dim=-1)`
					- `kl_loss = (teacher_T*(teacher_T.log() - student_T.log())).sum(1).mean()`
					- `ce_loss = CE(student_logits, labels)`
					- `loss_logits = alpha*(temperature**2)*kl_loss + (1 - alpha)*ce_loss`
			- 第二项 `loss_fea` 利用hook构造循环让学生中间层的特征图逼近教师中间层的特征图
				- `loss += (len(student) - i) * F.smooth_l1_loss(student[i].fea, teacher[i].fea)`
		- 第一项其实就包含KD和原始的精度损失，但是 第二项 相当于更进一步KD
	- clip grad 操作
		- `grad_norm = nn.utils.clip_grad_norm_(student_model.parameters(), max_norm)`
		- 介于 `loss.backward()` 和 `optimizer.step()` 之间

- `torchsummary.summary(model,input_size)`
	- 统计模型的参数量
	- **`torchsummary.summary` 不适合用于 Transformer 类语言模型**。  `torchsummary` 通常用于计算机视觉中的 CNN 模型，它假设模型接受一个单一的张量输入（如 `(batch, channels, height, width)`），并通过一次前向传播来统计参数和输出形状
	- 更现代的统计模型参数量的方法 `torchinfo.summary(model,input_data)`
		- `summary(model, input_data={"input_ids": inputs["input_ids"], "attention_mask": inputs["attention_mask"]})`
	- 当然对于目前主流模型也可以 直接 `print(model)`
		- **直接 `print(model)`**：打印的是模型在 `__init__` 方法中**模块注册的顺序**，即代码定义的顺序，而不是前向传播的执行顺序。
		- **使用 `torchinfo`（或其他类似工具）**：它会实际执行一次前向传播，并按照**前向传播的真实调用顺序**记录每一层的输入/输出形状、参数量等信息
