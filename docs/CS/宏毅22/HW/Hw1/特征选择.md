result=df.corr(method='spearman') ['tested_positive'].sort_values(ascending=False) # 相关系数大于0.8的特征提取出来

## 更鲁棒的查看相关特征

- 这是 `df.corr()` 的升级替代，可以应对更多类型的关系和任务。
```python
from sklearn.feature_selection import SelectKBest, f_classif, f_regression, mutual_info_classif, mutual_info_regression, chi2
df = pd.read_csv(....)
X = df.drop('target',axis=1)
y = df['target']
selector = SelectKBest(score_func=mutual_info_regression, k=10)
X_new = selector.fit_transform(X, y) # 选择与目标互信息最高的K个特征（能捕捉非线性关系）
selected_indices = selector.get_support(indices=True)
print("选中的列索引（整数位置）：", selected_indices)
# 例如：[2, 5, 7, 10, ...]
# 立即获取选中特征的列名（更推荐）
selected_names = X.columns[selector.get_support()].tolist()
print("选中的列名：", selected_names)
```

- 常用的评分函数：
	- **`f_regression`**：回归任务，单变量线性相关性的F检验（和皮尔逊相关类似但带p值）。
	- **`f_classif`**：分类任务，ANOVA F检验。
	- **`mutual_info_classif / mutual_info_regression`**：互信息，**能捕捉任意形式的依赖**，克服了 `df.corr()` 只看线性的缺点。
	- **`chi2`**：分类任务，卡方检验，只适用于非负特征（如词频）。
- 这些方法返回的 `X_new` 就是保留的特征子集。
