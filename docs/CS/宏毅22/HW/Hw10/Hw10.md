- 说明
	- 本次任务的目标是 构建对抗攻击样本去攻击黑盒模型，其实是攻击一堆白盒策略模型，然后根据攻击白盒模型得到的攻击样本去攻击黑盒模型


- 常规的模型pipeline
	- 数据集准备 -> 模型搭建 -> 训练器搭建 -> 推理过程
		- 训练器搭建中涉及 数据读取、优化器/损失函数设计以及学习率规划器等等环节


- 不过这里并不训练模型，而是训练 input 因此不会有训练器搭建和模型搭建，这里的模型会直接加载进来，同时本次最重要的就是训练输入，然后让输入变成攻击样本，因此主要是实现攻击方法
	- 数据集准备 -> 攻击算法实现 -> 攻击模型

- 数据集准备
	- 利用 python 自带的 glob和os工具读取准备的原始数据
	- `import glob`
	- `glob.glob('./data/*')` --- 它会产生一个 list包含`./data/`下的所有文件夹名称，比如 `./data/ship`
	- `import os`
	- `os.path.relpath('./data/ship','./data')` -> `ship`
	- 依旧是初始化的时候只保存文件路径，后续才拿入内存


- 三种攻击算法实现
	- fgsm
		- 只进行 一次输入的梯度更新，且学习率直接用 $\epsilon$
	- ifgsm
		- 进行 多次输入的梯度更新，学习率新指定通常更小，同时限制更新后的输入在 $[x-\epsilon, x+\epsilon]$
	- mifgsm
		- 引入 动量，每次采用动量更新
			- `decay * momentum + grad/(grad.abs().sum() + 1e-8)`
		- 其余与ifgsm方法一致
	- 上述方案均是采用 grad 的 sign 去指导加噪而不是直接用 grad 当噪声
