
## 模型剪枝（Model Pruning）

模型剪枝是一种常见的模型压缩方法，其核心思想是：

> 删除神经网络中不重要的参数、神经元、通道或结构，在尽量保持模型性能的前提下，减少模型的参数量、计算量和存储开销。

## 1. 基本原理

训练后的神经网络通常存在大量冗余参数，其中部分权重对最终输出影响较小。模型剪枝会根据某种重要性指标识别这些参数，并将其删除或置零。

典型流程为：

1. 训练一个完整模型。
    
2. 计算参数或结构的重要性。
    
3. 删除重要性较低的部分。
    
4. 对剪枝后的模型进行微调，恢复性能。
    
5. 必要时重复剪枝与微调。
    

---

## 2. 非结构化剪枝

非结构化剪枝以单个权重为单位进行删除。

例如，一个权重矩阵为：

[  
W=  
\begin{bmatrix}  
0.8 & 0.01 & -0.6\  
0.02 & 0.9 & -0.03  
\end{bmatrix}  
]

若剪枝阈值为 (0.05)，则可以得到：

[  
W'=  
\begin{bmatrix}  
0.8 & 0 & -0.6\  
0 & 0.9 & 0  
\end{bmatrix}  
]

最常见的方法是幅值剪枝，即认为绝对值较小的权重不重要：

[  
I(w_i)=|w_i|  
]

其中 (I(w_i)) 表示权重 (w_i) 的重要性。

### 特点

优点是剪枝粒度细、压缩率高，通常能够较好地保持模型精度。

缺点是会产生不规则的稀疏矩阵。普通 GPU 和深度学习框架不一定能够直接利用这种稀疏性，因此参数量虽然减少，实际推理速度不一定明显提升。

---

## 3. 结构化剪枝

结构化剪枝会删除完整的结构单元，例如：

- 神经元；
    
- 卷积通道；
    
- 卷积核；
    
- Transformer 的注意力头；
    
- Transformer 层；
    
- FFN 中间维度。
    

例如，对卷积层进行通道剪枝后，原输出形状为：

[  
(B,C,H,W)  
]

删除部分通道后变为：

$$  
(B,C',H,W), \qquad C'<C  
$$

结构化剪枝得到的模型仍然是规则的稠密模型，因此更容易在 GPU、CPU 和移动设备上获得真实的推理加速。

### 特点

优点是硬件友好，通常可以直接减少 FLOPs、显存占用和推理延迟。

缺点是剪枝粒度较粗，删除一个完整通道或注意力头可能造成更明显的性能下降。

---

## 4. 剪枝时机

### 训练后剪枝

先训练完整模型，再进行剪枝和微调。

流程为：

[  
\text{完整模型训练}  
\rightarrow  
\text{剪枝}  
\rightarrow  
\text{微调}  
]

实现简单，但高剪枝率下容易造成较大的精度下降。

### 训练中剪枝

在训练过程中逐渐提高稀疏率：

[  
s(t):0\rightarrow s_{\text{target}}  
]

其中 (s(t)) 表示训练时间 (t) 时的稀疏率。

这种渐进式剪枝可以使模型逐步适应参数被删除的过程，通常比一次性剪枝更加稳定。

### 初始化时剪枝

在正式训练之前就判断哪些参数可以被删除，例如根据初始化时的梯度或敏感度进行剪枝。

这种方法可以减少训练成本，但重要性判断通常更加困难。

---

## 5. 全局剪枝与局部剪枝

### 局部剪枝

每一层分别按照相同比例进行剪枝。

例如，每层都剪掉 (30%) 的参数。

优点是实现简单，但不同层对剪枝的敏感程度不同，统一比例可能不合理。

### 全局剪枝

将整个模型中的参数放在一起比较，根据全局重要性进行剪枝。

例如，在全模型中删除绝对值最小的 (30%) 权重。

全局剪枝允许不重要的层剪得更多、敏感的层剪得更少，因此通常优于固定比例的逐层剪枝。

---

## 6. 常见重要性指标

### 权重幅值

[  
I(w_i)=|w_i|  
]

权重绝对值越小，通常认为其影响越小。

对于结构化剪枝，可以使用一组参数的范数：

[  
I(G)=|W_G|_1  
]

或：

[  
I(G)=|W_G|_2  
]

其中 (G) 可以表示一个通道、神经元或注意力头。

### 基于梯度的重要性

根据删除参数后损失函数的变化判断重要性。

一阶近似为：

[  
\Delta L \approx  
\frac{\partial L}{\partial w_i}\Delta w_i  
]

当删除权重 (w_i) 时，有 (\Delta w_i=-w_i)，因此可以使用：

# [  
I(w_i)

\left|  
w_i\frac{\partial L}{\partial w_i}  
\right|  
]

该指标同时考虑参数大小和参数对损失的影响。

### 基于二阶信息的重要性

利用 Hessian 矩阵估计删除参数对损失函数的影响：

[  
\Delta L  
\approx  
\frac{1}{2}  
\Delta w^\top H\Delta w  
]

二阶方法通常更加准确，但计算开销较大。

### 激活重要性

对于通道或神经元，可以根据其输出激活判断重要性：

# [  
I_j

\mathbb{E}_{x}  
\left[  
|a_j(x)|  
\right]  
]

若某个神经元在大量样本上的激活值都很小，说明其对模型输出贡献可能较低。

## 7. 稀疏率

稀疏率表示参数中零值所占的比例：

# [  
\text{Sparsity}

\frac{\text{零参数数量}}  
{\text{参数总数量}}  
]

例如，模型共有 (1000) 个参数，其中 (700) 个被剪枝为零，则：

[  
\text{Sparsity}=70%  
]

对应的非零参数比例称为密度：

# [  
\text{Density}

1-\text{Sparsity}  
]

需要注意：

> 稀疏率高并不等于实际推理速度一定快，真实速度还取决于剪枝结构、硬件和稀疏算子支持。

---

## 8. 剪枝掩码

非结构化剪枝通常使用二值掩码：

[  
M_i\in{0,1}  
]

剪枝后的参数为：

[  
W'=W\odot M  
]

其中：

- (M_i=1)：保留该参数；
    
- (M_i=0)：删除该参数；
    
- (\odot)：逐元素乘法。
    

仅将参数置零并不一定会减小模型文件或加快计算。若底层仍然采用普通稠密矩阵乘法，这些零参数仍可能参与运算。

## 9. Transformer 和大语言模型中的剪枝

在 Transformer 中，常见的剪枝对象包括：

### 注意力头剪枝

删除不重要的注意力头。

多头注意力可表示为：

# [  
\operatorname{MHA}(X)

\operatorname{Concat}  
(\operatorname{head}_1,\ldots,\operatorname{head}_h)W^O  
]

剪枝后只保留部分注意力头，从而减小注意力计算量。

### FFN 神经元剪枝

Transformer 的 FFN 通常为：

# [  
\operatorname{FFN}(x)

W_2\sigma(W_1x)  
]

其中中间维度通常较大。删除部分中间神经元，可以缩小 (W_1) 和 (W_2) 的维度。

### 层剪枝

直接删除部分 Transformer Block：

[  
L\rightarrow L'  
]

层剪枝能够明显降低推理延迟，但通常比权重剪枝更容易损害模型能力。

### 半结构化稀疏

半结构化剪枝介于非结构化剪枝和结构化剪枝之间。

例如 (2:4) 稀疏表示每连续四个权重中恰好有两个为非零值：

[  
[\times,0,\times,0]  
]

它既保留了一定的剪枝灵活性，又比完全不规则的稀疏结构更容易获得硬件加速。

## 10. PyTorch 简单示例

```python
import torch
import torch.nn as nn
import torch.nn.utils.prune as prune

model = nn.Linear(128, 64)

# 对 weight 进行非结构化幅值剪枝
# 删除绝对值最小的 30% 权重
prune.l1_unstructured(
    model,
    name="weight",
    amount=0.3,
)

print(model.weight)
print(model.weight_mask)

# 将剪枝结果永久写入 weight
prune.remove(model, "weight")
```

结构化剪枝示例：

```python
prune.ln_structured(
    model,
    name="weight",
    amount=0.3,
    n=2,
    dim=0,
)
```

这里 `dim=0` 表示按照输出神经元对应的整行进行剪枝。

## 11. 模型剪枝的优缺点

### 优点

- 减少模型参数量；
    
- 减少模型存储空间；
    
- 降低计算量和显存占用；
    
- 有利于模型部署到边缘设备；
    
- 有时可以起到类似正则化的作用。
    

### 缺点

- 剪枝比例过高会降低模型性能；
    
- 剪枝后通常需要重新微调；
    
- 非结构化稀疏不一定带来实际推理加速；
    
- 不同层对剪枝的敏感程度不同；
    
- 稀疏模型需要硬件和底层算子支持。

## 12. 与量化和知识蒸馏的区别

|方法|核心思想|主要减少对象|
|---|---|---|
|剪枝|删除不重要的参数或结构|参数数量、计算结构|
|量化|降低参数和激活的数值精度|单个数值的存储位数|
|知识蒸馏|用大模型指导小模型学习|模型整体规模|

三者可以组合使用，例如：

[  
\text{知识蒸馏}  
+  
\text{结构化剪枝}  
+  
\text{INT8量化}  
]

从而同时减小模型规模、计算量和数值存储成本。

---

## 核心总结

> 模型剪枝通过删除神经网络中的冗余参数或结构来压缩模型。非结构化剪枝通常精度保持较好，但不规则稀疏难以获得真实加速；结构化剪枝直接删除通道、神经元、注意力头或网络层，更容易降低实际推理延迟。剪枝后通常需要微调，以恢复因参数删除而损失的性能。
