`input_nr` 主要在**一个前向算子有多个输出**时有用。

例如：

```python
u, v = f(a, b)
```

前向：

```text
a,b ──> f ──> u
           └─> v
```

对应同一个反向节点 `FBackward`：

```text
u 的 gradient edge = (FBackward, 0)
v 的 gradient edge = (FBackward, 1)
```

含义是：

```text
input_nr = 0  → 这份梯度是 ∂L/∂u
input_nr = 1  → 这份梯度是 ∂L/∂v
```

反向时：

```text
后续节点
   │
   ├── grad_u ──> (FBackward, 0)
   │
   └── grad_v ──> (FBackward, 1)

                 FBackward
                 /       \
              grad_a    grad_b
                 │        │
                 ▼        ▼
                 a        b
```

所以一句话：

> `input_nr` 用来告诉目标 autograd Node：**这条边传来的梯度属于该 Node 的第几个反向输入槽，也就是对应前向算子的第几个输出。**

对于普通单输出算子，如 `z = a*b`，通常只有一个槽，所以 `input_nr` 基本都是 `0`。
