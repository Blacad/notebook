```python
x = torch.tensor([1.0, 2.0], requires_grad=True)
y = x ** 2
grad = torch.autograd.grad( outputs=y, inputs=x, grad_outputs=torch.tensor([1.0, 1.0]) )
```


这里的 `grad` 返回的是一个**元组**，其中包含输入 `x` 对应的梯度：

```python
(tensor([2., 4.]),)
```

因此：

```python
grad[0]
# tensor([2., 4.])
```

## 为什么是 `[2, 4]`

你的计算是：

```python
x = [x_1, x_2]
y = x ** 2 = [x_1^2, x_2^2]
```

也就是一个向量到向量的函数：

$\mathbf y= \begin{bmatrix} y_1\\ y_2 \end{bmatrix} = \begin{bmatrix} x_1^2\\ x_2^2 \end{bmatrix}$

它的完整导数是 Jacobian 矩阵：

$\frac{\partial \mathbf y}{\partial \mathbf x} = \begin{bmatrix} \frac{\partial y_1}{\partial x_1} & \frac{\partial y_1}{\partial x_2}\\ \frac{\partial y_2}{\partial x_1} & \frac{\partial y_2}{\partial x_2} \end{bmatrix} = \begin{bmatrix} 2x_1 & 0\\ 0 & 2x_2 \end{bmatrix}$

代入 `x=[1,2]`：

$J= \begin{bmatrix} 2 & 0\\ 0 & 4 \end{bmatrix}$

但 `torch.autograd.grad` 默认不会直接返回整个 Jacobian，而是计算一个**向量-Jacobian 乘积**，即 VJP：

$\mathbf v^\top J$

其中 `grad_outputs` 就是上游向量：

```python
grad_outputs=torch.tensor([1.0, 1.0])
```

即：

$\mathbf v= \begin{bmatrix} 1\\ 1 \end{bmatrix}$

因此：

$\mathbf v^\top J = \begin{bmatrix} 1 & 1 \end{bmatrix} \begin{bmatrix} 2 & 0\\ 0 & 4 \end{bmatrix} = \begin{bmatrix} 2 & 4 \end{bmatrix}$

所以返回：

```python
(tensor([2., 4.]),)
```

## 另一种等价理解

`grad_outputs=[1,1]` 相当于先把输出加权求和：

$L=1\cdot y_1+1\cdot y_2$

也就是：

$L=x_1^2+x_2^2$

再计算：

$\frac{\partial L}{\partial \mathbf x} = \begin{bmatrix} 2x_1\\ 2x_2 \end{bmatrix} = \begin{bmatrix} 2\\ 4 \end{bmatrix}$

因此它可以近似理解为：

```python
weighted_y = (y * grad_outputs).sum()
grad = d(weighted_y) / dx
```

## 改变 `grad_outputs`

例如：

```python
grad_outputs=torch.tensor([1.0, 2.0])
```

相当于：

$L=y_1+2y_2=x_1^2+2x_2^2$

于是：

$\frac{\partial L}{\partial \mathbf x} = \begin{bmatrix} 2x_1\\ 4x_2 \end{bmatrix} = \begin{bmatrix} 2\\ 8 \end{bmatrix}$

返回：

```python
(tensor([2., 8.]),)
```

所以 `grad_outputs` 的含义是：**指定每个输出分量对最终反向梯度的权重，也就是从输出端传入的上游梯度。**
