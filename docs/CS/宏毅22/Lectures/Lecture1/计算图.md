
***计算图本质上就是记录前向过程中各算子的依赖关系和反向函数，使反向传播时能按正确路径调用各算子保存的信息并计算、累积梯度***

- ***PyTorch autograd 分成两部分记***
	- **图本身**：`grad_fn` + 节点连接(`grad_fn.next_functions`) + 保存的前向信息
	- **梯度结果**：最后通过 `AccumulateGrad` 等机制累积到叶子 Tensor 的 `.grad` 中
	- 所以 `.grad` 严格来说不是计算图的一部分，而是**计算图执行后的一个结果存储位置**
	- **Tensor 本身并不是反向计算图的节点主体**，PyTorch 的反向图主要是由这些 `autograd Node` 连接起来的
		- `next_functions` 本身是一个 tuple `(Node,input_nr)`
		- `Node` 很好理解就是它的梯度继续流向的 autograd Node
		- `input_nr` 是针对可能有多个输出的算子而言的，用来指示究竟是算子的哪个输出 [例子](./多输出算子.md)
		-  如果该 autograd Node 梯度会流向多个tensor，那么它的 `next_functions` 是 tuple of tuple `((Node,input_nr),(Node,input_nr),...)`

```text
Tensor
  │
  └── grad_fn ─────> autograd Node
                         │
                         ├─ 反向计算规则
                         ├─ saved tensors / 前向信息
                         └─ next_functions → 其他 autograd Node
```

- 梯度
	- `z.backward()`
		- 当执行该操作后，包含`z` 的计算图的所有叶子结点都会通过 `AccGrad` 累积梯度到 `.grad` ，但是中间节点的梯度并不会持久化存储在它们的 `.grad` 中(除非，使用 `y.retain_grad()`)
	- `torch.autograd.grad(outputs,inputs,grad_outputs)`
		- 当执行该操作后，直接计算并返回 `outputs` 对指定 `inputs` 的梯度，所有梯度都不会存储进 `.grad` 中(除非，有节点使用了 `y.retain_grad()`，它的梯度依然会被存储进 `.grad` 中)
	- `y.retain_grad()`
		- 显式指定要保存 y 的 grad，默认依然是 累加保存(不是覆盖保存) grad，但是向后传递的梯度是每次来的grad而不是累加 grad
	- `y_detached=tensor.detach().clone()`
		-  `detach()`：断开与原计算图的梯度关联
		- `clone()`：复制一份独立数据，避免和原 Tensor 共享底层存储
		- 因此 `y_detached` 可以近似看作一个**用当前数值重新创建出来的新 Tensor**
	- `requires_grad=False`
		- 从一开始就不要求追踪它的梯度，它被视作常量 Tensor


| 操作                       | 改变 Dropout/BN 行为 | 是否构建计算图 | 能否 backward |
| ------------------------ | ---------------- | ------- | ----------- |
| `model.train()`          | 是，训练模式           | 是       | 是           |
| `model.eval()`           | 是，评估模式           | 是       | 是           |
| `torch.no_grad()`        | 否                | 否       | 否           |
| `torch.inference_mode()` | 否                | 否       | 否           |


- 在 Tensor 的计算中，一定要有==计算图意识==，考虑该行为是否应该在当前计算图中，一些常见的切断计算图的情形
	- Tensor切断之前的计算图，从 autograd 视角，可以近似理解为“拿当前数值重新作为一个新的起点” ---- `y_detached=y.detach().clone()`
	- 完全不想涉及计算图时 --- `with torch.no_grad():`
		- 当然可能会有类似 `model.weight.data += tensor` 的操作也是为了规避计算图，但是最好还是采取 `with torch.no_grad():`
