- [Goal of Explainable ML](../../Slides/Lecture9/xai_v4.pdf#page=10)
	- 给答案以理由 是 可解释模型的一种重要视角
	- 我私认为可解释模型应该是能够将 hidden state 是什么解释清楚，并将各部分 layers 在具体干什么

- 为何 可解释分析 很重要
	- 因为你的模型本身关注的部分，和你认为它关注的部分可能很不一样

- 两类可解释性
	- Local Explanation
		- 为什么 该图片 是猫？
	- Global Explanation
		- 猫应该长什么样？

- Local Explanation 分析
	- 分析输入
		- 针对输入的各部分分析(LIME)，看输入的那部分最重要，[如图](../../Slides/Lecture9/xai_v4.pdf#page=14) 

	- 分析梯度
		- 依据 输入gradient 来分析(loss对输入求导)，得出 Saliency Map，[如图](../../Slides/Lecture9/xai_v4.pdf#page=16)
		- [SmoothGrad](../../Slides/Lecture9/xai_v4.pdf#page=24)
			- 给训练的数据随机添加 noise，然后得到 噪声输入的 saliency maps，最后将这些 maps 平均
	
	- 分析 hidden state(怎么分析网络如何处理数据呢)
		- 可视化[Visualization](../../Slides/Lecture9/xai_v4.pdf#page=26-27)
			- 将模型的 hidden states 利用 PCA 或 t-SNE 降维到 2 维就可以画出来了看了
		- 探针 [Probing](../../Slides/Lecture9/xai_v4.pdf#page=29)
			- 训练 分类器 来分析 hidden states
			- 探针可以用多种模型并非只是分类器


- Global Explanation 分析
	- 构建数据来观察 网络各部分 主要处理什么
		- 具体做法是在一堆数据中找到通过该部分后输出和较大的数据(高激活说明输入与 filter 学到的特征模板匹配)
		- [如图](../../Slides/Lecture9/xai_v4.pdf#page=34) 就是找 filter 1 处理后对应输出较大的数据，然后分析这些数据的特征，就可以知道 filter 1 在处理什么
