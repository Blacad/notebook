PCA 和 t-SNE 都常用于**降维与数据可视化**，但目标和原理不同。

### PCA：主成分分析

PCA（Principal Component Analysis）是一种**线性降维方法**。核心思想是：

> 找到数据中方差最大的几个方向，把原始数据投影到这些方向上。

例如原始数据是 100 维，希望降到 n 维，PCA 会寻找n个正交方向：

$$w_1,\quad w_2,...$$

使投影后的数据尽可能保留原数据的方差信息。

数学上，每个主成分均通过以下方式求得(后续主成分需要与之前主成分正交)：

$$w_1=\arg\max_{\|w\|=1}\operatorname{Var}(Xw)$$

- $||w||=1$ 表示是单位向量 
- $X$ 就是原数据
- $Var$ 是方差

实际计算通常通过协方差矩阵的特征值分解或 SVD 完成。

特点：

- 线性变换
    
- 速度快、结果稳定
    
- 能较好保留数据的**全局结构**
    
- 可以用于真正的数据降维、压缩和后续模型输入
    
- 如果原数据存在复杂非线性结构，二维 PCA 图可能分不开
    

---

### t-SNE：t 分布随机邻域嵌入

t-SNE（t-distributed Stochastic Neighbor Embedding）是一种**非线性降维方法**，主要用于高维数据的 2D/3D 可视化。

它更关注：

> 在高维空间中彼此接近的点，降维之后也应该尽量靠近。

比如在高维特征空间中：

```text
A1 A2 A3       B1 B2 B3
```

形成两个局部群体，t-SNE 会尽量让二维空间中也表现为：

```text
A A A          B B B
```

它首先根据高维空间中的距离定义点之间的相似概率，然后在低维空间构造另一套概率分布，并通过最小化两者之间的 KL 散度：

$$KL(P\|Q) = \sum_{i,j}p_{ij}\log\frac{p_{ij}}{q_{ij}}$$

来寻找低维坐标
- 高维的相似概率是通过两个条件概率的平均再除所有样本点得出的 即 $$p_{i,j}=\frac{p_{j|i}+p_{i|j}}{2N}$$
- 其中条件概率的含义是 $p_{j|i}$ 以样本点 i 为中心时，把 j 当成邻居的概率有多大

t-SNE 中低维相似度使用 **Student-t 分布**，这样可以缓解降维时点大量拥挤在一起的问题
- Student-t 是一族“从重尾分布逐渐过渡到高斯分布”的分布，由 自由度 $\mu$ 调节

特点：

- 非线性
    
- 非常适合观察**局部聚类结构**
    
- 常用于神经网络 embedding / feature 的可视化
    
- 计算比 PCA 慢
    
- 对参数和随机种子比较敏感
    
- 二维图中不同簇之间的**距离、大小不能简单解释**


|      | PCA       | t-SNE     |
| ---- | --------- | --------- |
| 类型   | 线性        | 非线性       |
| 主要保持 | 全局方差结构    | 局部邻域结构    |
| 速度   | 快         | 慢         |
| 稳定性  | 高         | 相对低       |
| 常见用途 | 降维、压缩、预处理 | 2D/3D 可视化 |
| 聚类展示 | 一般        | 通常很好      |

一句话概括：

**PCA 是寻找“信息量最大的投影方向”，t-SNE 是尽量保持“谁和谁原本是邻居”。**
