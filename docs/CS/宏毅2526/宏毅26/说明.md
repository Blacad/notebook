## 李宏毅生成式人工智能 2026

- [26春网址](https://speech.ee.ntu.edu.tw/~hylee/ml/2026-spring.php)

2026 年春季课程由国立台湾大学李宏毅教授讲授，官网名称仍是 Machine Learning，但主体内容更聚焦于 LLM 与 AI Agent：从 Agent 如何使用工具、管理上下文与协作，深入到推理加速、长上下文和 Harness Engineering，再讨论模型的自我修正、自我提升与 Agent 的持续演化。整门课围绕“如何让 AI 更有效地完成任务，以及如何从经验中成长”展开，既讲模型内部机制，也讲模型之外的系统设计，并关注算力成本、评估可靠性、遗忘与目标对齐等限制。

- 与往年课程的衔接：[2022 年笔记](../../%E5%AE%8F%E6%AF%8522/%E8%AF%B4%E6%98%8E.md) 偏向广泛的深度学习基础与经典模型，[2025 年笔记](../%E5%AE%8F%E6%AF%8525/%E8%AF%B4%E6%98%8E.md) 系统整理 LLM 的训练、架构、推理与评估；2026 年则进一步围绕 Agent 的运行机制与自我成长展开，三者可以结合阅读，遇到基础概念时再回查前两年的内容。
- 学习与记录方式：结合课程视频、Slides 和相关论文整理关键概念、原理与方法对比；本页的 Unit / Lecture 是笔记按主题划分的组织方式，不等同于官网的逐周课程安排，官网另有专题演讲等材料。
- 作业方面，官网列出 10 次作业，涵盖恶意指令防御、Agent 做 AI 工程、快速推理、Transformer 训练、避免遗忘的微调、模型编辑与合并、Test-Time Scaling、Flow Matching 和语音语言模型；实践内容比下方 Lecture 表格的主题更广。
- 同样的作业会在 209 上做，用 git 管理
