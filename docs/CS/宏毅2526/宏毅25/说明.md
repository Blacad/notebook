## Lecture 简介

| Lecture                                                             | 主题            | 内容概要                                                                                                                                                        |
| ------------------------------------------------------------------- | ------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [L1 生成式 AI](Lectures/Lecture1/Generative%20AI.md)                   | 总览            | 生成式模型的推理(input→token→自回归)、训练(架构+参数、三阶段训练)、优化手段(提示词/Agent工程、微调、Model Editing、Model Merging)三大机制，以及"通用"概念的语义变迁                                                |
| [L2 Agent](Lectures/Lecture2/Agent.md)                              | AI Agent      | Agent 的观察-行动-奖励框架、LLM 做 Agent 的优势；利用经验(Agent Memory/RAG)、利用工具(Function Call)、信息判断力；做计划(Plan-and-Solve、树搜索、World Model)，最后指出 Plan 与 Reasoning 本质一致           |
| [L3 模型可解释性](Lectures/Lecture3/LLM%20Explainability.md)              | 可解释性          | 从单神经元(激活/移除)到一层(功能向量 FV、[SAE](Lectures/Lecture3/SAE&FV.md))再到一群神经元(Circuit)自底向上理解模型；Residual Stream + Logit Lens、Patchscopes、循环解析等"透明思维"视角                  |
| [L4 Transformer 的伙伴们](Lectures/Lecture4/Transformer's%20Friends.md) | 架构            | 从 RNN/Attention 的优劣对比出发，推导 RNN≈Linear Attention，进而介绍 Retention、Mamba、DeltaNet(梯度下降视角)、Titans 等新型序列架构；[GQA/DeltaNet 实践](Lectures/Lecture4/GQA&DeltaNet实践.md) |
| [L5 预训练与对齐](Lectures/Lecture5/PreTrain&Alignment.md)                | 预训练/对齐        | PreTrain(海量语料、数据增强与清洗)与 Alignment(SFT/RLHF，less is enough, quality is all)；知识蒸馏、对齐数据的有效性分析(四类/三类数据)、PreTrain 的后遗症                                           |
| [L6 后训练](Lectures/Lecture6/PostTrain.md)                            | 后训练           | 将 PostTraining 视为持续学习，讨论其导致的灾难性遗忘及解决方案：Experience Replay、Paraphrase、Self-output，并指出 RL-Style 不易遗忘的原因                                                        |
| [L7 推理](Lectures/Lecture7/Reasoning.md)                             | Reasoning     | Reasoning 的组成(Verification/Explore/Planning)与四种获得方式：CoT、推理工作流(self-consistency、Process Verifier、Beam Search)、模仿学习、强化学习；以 DeepSeek-R1 训练过程收尾                 |
| [L8 推理长度控制](Lectures/Lecture8/Reasoning%20Enough.md)                | Reasoning     | Reasoning 并非越长越好，介绍通过 CoT(Chain of Draft)、模仿学习(只学最短)、RL(长度惩罚/指定长度)等手段控制推理长度                                                                                 |
| [L9 评估](Lectures/Lecture9/Eval.md)                                  | 评测            | 对 Benchmark 跑分的质疑(背答案、数据改造)，更有效的 Benchmarks(ARC-AGI、Chatbot Arena/Elo)，以及 Goodhart's Law：指标一旦成为目标就不再是好指标                                                    |
| [L10 模型编辑](Lectures/Lecture10/Model%20Editing.md)                   | Model Editing | 向模型植入知识(区别于 PostTraining 学技能)；三个评估维度 Reliability/Generalization/Locality；不动参数(RAG、IKE)与改参数(ROME、MEND/Meta-Learning)的方法                                      |
| [L11 模型合并](Lectures/Lecture11/Model%20Merging.md)                   | Model Merging | 以向量视角看待模型权重，用向量加减赋予/剥夺能力：相加、相减、类比三类基本方法，以及向量非正交带来的问题与解决思路                                                                                                   |
| [助教课](Lectures/助教课/多卡训练.md)                                         | 工程实践          | 多卡训练(DeepSpeed/ZeRO、FSDP、混合精度、Activation Re-computation)、FlashAttention、Liger Kernel、量化；[PagedAttention](Lectures/助教课/PagedAttention.md) 与 vLLM 的模块化架构      |
