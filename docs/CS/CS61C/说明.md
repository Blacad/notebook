## UC Berkeley CS61C · Great Ideas in Computer Architecture

- 课程方向：**计算机组成与硬件—软件接口**，也称 Machine Structures。
- [Fall 2024 课程归档](https://web.archive.org/web/20241219154359/https://cs61c.org/fa24/)（保留原说明中的入口；本次整理依据本地 Slides，不依赖归档网页补齐内容）。

CS61C 研究程序如何从高层代码走到真实机器：先用 C 理解位表示、指针与内存，再用 RISC-V 看清算术、访存、分支和过程调用，随后用数字逻辑构建处理器的数据通路与控制，加入流水线、缓存和虚拟内存，最后扩展到多核、分布式计算、科学应用、数据中心和可靠性。它既不是纯软件课，也不只是背硬件名词，而是用一条跨层链路回答：**程序究竟怎样执行，为什么会慢，哪里可能出错，以及如何有根据地改进？**

- 六个贯穿全课的思想：**抽象、Moore’s Law、局部性与存储层次、并行、性能测量与改进、通过冗余提高可靠性**。历史技术趋势与器件跑分按讲义年代理解，不视作实时结论。
- 学习基础：基本编程、数组/函数、二进制与简单代数；数字逻辑和汇编会在课内逐步建立。纸上画地址、位域、时序和状态变化，是很重要的学习方式。
- 本地讲义列出四个项目：**snek**（C 与调试）、**CS61Classify**（RISC-V 汇编）、**CS61CPU**（构建 CPU）、**CS61kaChow**（性能优化）。这里整理概念与机制，不代替项目实现，也不沿用历史 deadline。

## 记录方式与阅读边界

- 沿用前两套课程笔记：主题分点、关键公式/指令、易混概念与原课件截图结合；链接使用 **PDF 实际页码**，不依赖页脚的旧编号。
- 大部分普通讲义配 2–3 张图，合并流水线讲义配 5 张；缓存速查仅有 1 页原图。截图保留原貌，教学简化或笔误以旁边的说明为准。
- 硬件模型以课程中的 **RV32I 与简化处理器**为基础。固定指令宽、时序、延迟和容量示例不是对所有 RISC-V 扩展或商用 CPU 的通用保证。
- 区分 C 语言规则、ISA 行为、ABI 约定和微体系结构实现。例如 C 有符号溢出、寄存器低位截断、函数栈对齐不是同一层规则。
- 关键边界已补充说明：jalr 清最低位、标准 ABI 栈对齐、invalid 不必然是 compulsory miss、TLB miss 不等于缺页、缺页也不必然代表去磁盘。部分规范细节附有官方规范链接。
- 记录以本地资料为主；没有声称已运行原始项目、OpenMP 多线程实验、RISC-V 模拟器或硬件实现。

## 串起全课的几条线

- **表示与执行**：L1 位表示 → L2–5 C/内存 → L7–13 ISA 与 CALL → L14–20 用电路执行指令。
- **性能与数据移动**：L21–22 的性能公式/流水 → L24–27 的局部性 → L28–32 的并行与通信 → L35/L37 的应用与机房规模。
- **正确性与边界**：C 的类型/对象生命周期 → ABI 保存约定 → 逻辑/时序 → 同步与 coherence → VM 保护 → ECC/RAID/恢复。
- **复习建议**：学汇编时画寄存器/地址表，学流水线时画逐周期图，学 cache/TLB 时逐次更新状态，学性能时始终带单位并明确模型。
