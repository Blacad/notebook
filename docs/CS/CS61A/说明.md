- 在算法实践中有关python的[补充知识](https://onefly.top/zero2Leetcode/00_python_basics)
	- 算法时非常重要的[补充基础细节](https://onefly.top/zero2Leetcode/00_python_basics/05-coding-tricks/index.html)
	- [补充数据结构细节](https://onefly.top/zero2Leetcode/01_data_structures/index.html)
	- [补充基础算法细节](https://onefly.top/zero2Leetcode/02_algorithms/index.html)
	- 算法实践与算法课之间其实存在不小的gap，由于算法课通常在数学层面上分析算法的复杂度和正确性，且通常语言无关，因此只能从理论层面上理解，真正动手实践 == 语言特性 + 理论理解
		- 语言特性就是上面的补充知识
		- 理论理解就是算法课里教的知识，FDS + ADS
	- 其实最好的方法就是在学完 理论知识 + 语言基础后 去直接刷 Hot100(Leetcode)，然后有不会的分析题解再回来看各种数据结构或者算法的复习(主要面向求职)
