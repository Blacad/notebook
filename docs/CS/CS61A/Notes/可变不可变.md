Python中的可变类型主要包括：

- **list**（列表）
- **dict**（字典）
- **set**（集合）
- **bytearray**（字节数组）
- 用户自定义的类实例（通常情况下）

## 可变类型的特点

可变类型被称为"可变"是因为：

1. **对象内容可以修改**：可以在不改变对象身份的情况下修改其内容
2. **原地修改**：可以通过方法直接修改对象，而不需要创建新对象
3. **共享引用影响**：多个变量引用同一对象时，修改会影响所有引用


## 不可变类型及其特点

不可变类型包括：

- **int**（整数）
- **float**（浮点数）
- **bool**（布尔值）
- **complex**（复数）
- **str**（字符串）
- **tuple**（元组）
- **frozenset**（冻结集合）
- **bytes**（字节串）
- ....

这些类型被称为"不可变"是因为：

1. **内容不能修改**：一旦创建，对象的内容就不能被改变
2. **操作产生新对象**：对这些类型进行操作时会创建新的对象
3. **引用独立**：修改一个引用不会影响其他引用

***数字 + str + tuple + bytes + frozenset + range + None 是不可变的***

## 核心区别

主要区别在于：***对象本身的状态是否允许在身份（**`id`**）不变的情况下发生改变。***

- **可变类型**：对象创建后，可以直接修改对象内部状态，而对象本身仍然是同一个对象，因此 `id` 通常保持不变
- **不可变类型**：对象创建后，其状态不能再被修改。所谓对不可变对象进行“修改”，实际上是得到另一个表示新值的对象，然后让变量重新绑定到该对象；原对象本身始终没有发生变化

在 Python 中，***变量本质上是名称（引用），变量本身并不是对象，而是绑定到某个对象上***

其实 Python 的：

```
b = a
```

**永远不是拷贝对象，而是让 `a`、`b` 指向同一个对象**

例如：

```
a = 1
a = a - 1
```

最初：

```
a ───> int 对象 1
```

执行 `a - 1` 后，会得到表示 `0` 的另一个 `int` 对象，然后 `a` 重新绑定：

```
原来：
a ───> int 对象 1

之后：
a ───> int 对象 0
```

因此，原来的 `int` 对象 `1` 从始至终都没有被修改；只是变量 `a` 不再引用它，而改为引用结果对象 `0`。当没有任何变量继续引用旧对象时，该对象之后才可能被垃圾回收。

再比如：

```
a = 10
b = a

a += 1
```

此时实际发生的是：

```
原来：
a ─┐
   ├──> 10
b ─┘

之后：
a ───> 11
b ───> 10
```

需要注意，`id(obj)` 严格来说表示的是**对象的身份标识**，并不由 Python 语言规范保证一定等于内存地址。在 CPython 中，`id(obj)` 通常使用对象的内存地址实现，因此实践中常可以把它近似理解为对象地址。

所以，更准确的理解是：

> **可变性描述的是“同一个对象能否改变自身状态”。可变对象可以在** `**id**` **不变的情况下修改内容；不可变对象不能修改自身状态，所谓修改实际上是让变量重新绑定到另一个结果对象。**

另外，“另一个对象”也不一定意味着每次都重新申请一块内存。例如 CPython 会缓存部分小整数，因此新的结果对象可能是一个已经存在的对象，而不是刚刚创建的对象。
