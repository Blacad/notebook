分成三类理解：**赋值、浅拷贝、深拷贝**

### 1. 赋值：不是拷贝

```python
a = [1, 2]
b = a
```

此时：

```text
a ─┐
   ├──> [1, 2]
b ─┘
```

`a` 和 `b` 指向同一个对象：

```python
id(a) == id(b)   # True
```

因此：

```python
b.append(3)
```

会同时表现为：

```python
a == [1, 2, 3]
b == [1, 2, 3]
```

所以：

> `b = a` 只是增加了一个引用，不会创建新对象。

---

### 2. 浅拷贝：复制最外层对象

例如：

```python
import copy

a = [[1, 2], [3, 4]]
b = copy.copy(a)
```

结构是：

```text
a ──> list A ──┬──> [1, 2]
                └──> [3, 4]
                        ^
b ──> list B ───────────┘
                 
```

最外层已经是两个对象：

```python
id(a) != id(b)
```

但里面的元素仍然指向相同对象：

```python
id(a[0]) == id(b[0])   # True
```

所以：

```python
b.append([5, 6])
```

不会影响 `a`，因为修改的是外层 `b`：

```python
a = [[1, 2], [3, 4]]
b = [[1, 2], [3, 4], [5, 6]]
```

但是：

```python
b[0].append(100)
```

会影响 `a`：

```python
a = [[1, 2, 100], [3, 4]]
b = [[1, 2, 100], [3, 4]]
```

因为内部 `[1, 2]` 是共享的。

因此：

> **浅拷贝 = 创建新的外层对象，但内部元素仍然只是复制引用**

常见浅拷贝：

```python
b = copy.copy(a)

b = a.copy()       # list / dict 等
b = a[:]           # list
b = list(a)
b = dict(a)
```

---

### 3. 深拷贝：递归复制内部对象

```python
import copy

a = [[1, 2], [3, 4]]
b = copy.deepcopy(a)
```

可以理解为：

```text
a ──> list A ──┬──> list C [1,2]
                └──> list D [3,4]

b ──> list B ──┬──> list E [1,2]
                └──> list F [3,4]
```

因此：

```python
b[0].append(100)
```

不会影响 `a`：

```python
a = [[1, 2], [3, 4]]
b = [[1, 2, 100], [3, 4]]
```

所以：

> **深拷贝 = 不仅复制外层对象，还递归复制内部需要复制的对象。**

---

## 和不可变对象的关系

这里有个很重要的点。

对于：

```python
a = 10
b = copy.copy(a)
```

由于 `int` 是不可变对象，完全没有必要真的复制一个新的 `10`：

```python
id(a) == id(b)
```

通常仍然成立。

类似：

```python
a = "hello"
b = copy.copy(a)
```

可能还是：

```text
a ─┐
   ├──> "hello"
b ─┘
```

这是安全的，因为 `"hello"` 本身根本不能被修改。

因此：

> **拷贝的核心目的主要是隔离可变对象的修改。对于不可变对象，共享同一个对象通常没有任何问题**

---

### 最核心的关系

可以这样记：

| 操作               | 外层对象 | 内部可变对象 |
| ------------------ | -------- | ------------ |
| `b = a`            | 共享     | 共享         |
| `copy.copy(a)`     | 新对象   | 共享         |
| `copy.deepcopy(a)` | 新对象   | 通常也复制   |

最典型的例子：

```python
a = [[1, 2]]

b = a
c = copy.copy(a)
d = copy.deepcopy(a)
```

对应：

```text
b ───────┐
         ↓
a ───> 外层 list ───> 内层 list
                    ^ 
c ───> 新外层 list ──┘
                  仍共享内层

d ───> 新外层 list ───> 新内层 list
```

所以一句话：

> **赋值复制的是引用；浅拷贝复制一层对象；深拷贝递归复制对象。**

这也是 Python 中“变量是引用”这个模型在拷贝问题上的直接体现。
